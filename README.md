# Portfolio Assets Repository

Repository ini khusus digunakan sebagai Content Delivery Network (CDN) eksternal untuk menyimpan aset statis dari website portofolio Benaya Bagas Christianto.

Tujuan utama pemisahan repositori ini adalah untuk meringankan beban penyimpanan dan *bandwidth* pada server utama website portofolio, sehingga dapat memberikan performa pemuatan halaman yang lebih cepat dan arsitektur sistem yang lebih terstruktur.

## Daftar Aset yang Disimpan

Repository ini menyimpan berbagai jenis file statis yang diakses secara publik oleh website portofolio, antara lain:

- Gambar latar belakang proyek portofolio.
- Dokumen PDF sertifikat keahlian dan kelulusan.
- File basis data (SQL) yang dapat diunduh sebagai bahan portofolio.
- Dokumen perancangan jaringan (PKT) dan dokumen teks pendukung.
- Curriculum Vitae (CV) terbaru.

## Catatan Tambahan

Repository ini tidak memuat kode sumber (*source code*) utama dari website portofolio. Aset di dalam repository ini dipanggil langsung oleh website menggunakan URL mentah (*raw link*). 

Semua hak cipta atas sertifikat, identitas pribadi, dan rancangan sistem yang tersimpan di sini adalah milik Benaya Bagas Christianto.
